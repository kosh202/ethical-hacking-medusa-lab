# Wordlists do laboratório

Durante o teste FTP foram preparadas listas simples de usuários e senhas para uso restrito ao laboratório. As listas não são distribuídas neste repositório.

Use somente candidatos sintéticos ou autorizados. Nunca adicione senhas reais, reutilizadas, dados pessoais ou listas obtidas sem autorização. Mantenha arquivos locais de usuários e senhas fora do Git e registre na documentação apenas a finalidade e o resultado geral do teste, sem os valores.
